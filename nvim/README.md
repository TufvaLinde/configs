# Neovim config

Set up and linked automatically by `../install.sh`. All shortcuts: [CHEATSHEET.md](CHEATSHEET.md) (or `Space ?` inside nvim). Config map: [main README](../README.md#repo-layout).

So far the config is tailored mostly for writing LaTeX in nvim. I used [this](https://www.ejmastnak.com/tutorials/vim-latex/intro/) guide by Elijan Mastnak to set everything up. One difference from the guide: PDFs are viewed in the terminal with `tdf` (see `plugin/tex.vim` and `../bin/texview`) instead of Zathura/Skim.
